# Claude Portfolio + Royal White Content Integration

Base: user-uploaded `portfolio-phase1.zip` (Claude design). Original dark-blue visual system and React component architecture retained.

Integrated: updated Datoway role/intro/about, six skill categories, career journey, certifications placeholders, royal portfolio creative ticker, infinitely moving photo marquee, revised TOMS/MethaneWatch copy, and updated resume from Royal White project. Original Claude images and contact form retained.

**Accuracy:** Certification titles and pictures are intentionally placeholders; do not publish invented credentials. TOMS/MethaneWatch personal contribution language is qualified; no ownership of entire platforms asserted.

**Reduced motion:** Automatic tickers disable motion for users requesting reduced motion.

Run: `npm install` then `npm run dev`; validate with `npm run build`.
